## 📱 Инструкция: Как собрать APK-файл для Android

Если вы хотите собрать установочный файл `.apk` из исходного кода этого проекта, следуйте инструкции ниже. Проект использует фреймворк **Briefcase** (часть экосистемы BeeWare), который автоматически управляет зависимостями Android.

### 🛠️ Что понадобится:
- **Python 3.10+** (установленный и добавленный в PATH).
- **Git** (для клонирования репозитория).
- Стабильное интернет-соединение (при первой сборке Briefcase скачает Java JDK 17 и Android SDK, это может занять 10-20 минут).

### 🚀 Пошаговая сборка (Windows / macOS / Linux):

**1. Клонируйте репозиторий и перейдите в папку проекта:**
```bash
git clone https://github.com/ВАШ_НИК/ИМЯ_РЕПОЗИТОРИЯ.git
cd ИМЯ_РЕПОЗИТОРИЯ
2. Создайте виртуальное окружение и установите Briefcase:

bash
# Создание виртуального окружения
python -m venv .venv

# Активация (Windows)
.venv\Scripts\activate
# Активация (macOS/Linux)
source .venv/bin/activate

# Установка Briefcase
pip install briefcase
3. Сгенерируйте структуру Android-проекта:

bash
briefcase create android
Примечание: Во время этого шага терминал может запросить принятие лицензий Google. Нажимайте y и Enter.

4. Скомпилируйте приложение:

bash
briefcase build android
Первый запуск может занять длительное время, так как скачиваются все необходимые библиотеки.

5. Упакуйте готовый APK-файл:

bash
briefcase package android -p debug-apk
📂 Где найти готовый файл?
После успешного выполнения всех команд в корневой папке проекта появится директория dist/. Внутри неё будет лежать готовый файл pythonquizapp-1.0.0-debug.apk.

Вы можете перекинуть этот файл на ваш Android-смартфон и установить его (потребуется разрешить установку из неизвестных источников в настройках телефона).

# 🐍 Python Quiz App

Интерактивное кроссплатформенное приложение-викторина для проверки и изучения знаний языка Python. Написано на Python с использованием фреймворка **BeeWare (Toga)**.

## ✨ Основные возможности

- **3 уровня сложности:** Новичок, Средний, Тяжелый.
- **База данных:** Более 250 уникальных вопросов с подробными пояснениями.
- **Раунды по 10 вопросов:** В рамках одного раунда вопросы не повторяются (выборка случайная).
- **Мгновенная обратная связь:** Подсветка правильных и неправильных ответов, а также пояснение к каждому вопросу.
- **Статистика:** Подсчет очков и итоговый экран после каждого раунда.
- **Нативный интерфейс:** Приложение собирается в `.apk` и отлично работает на Android.

## 🛠️ Стек технологий

- **Язык:** Python 3
- **UI Framework:** [Toga](https://toga.readthedocs.io/) (часть проекта BeeWare)
- **База данных:** SQLite3 (встроенная)
- **Упаковка:** Briefcase
