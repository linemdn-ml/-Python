🐍 Интерактивное приложение-викторина по Python для Android. Три уровня сложности, случайные вопросы без повторов и подробные пояснения. Написано на Python (BeeWare/Toga).

# 🐍 Python Quiz App

Интерактивное кроссплатформенное приложение-викторина для проверки и изучения знаний языка Python. Написано на Python с использованием фреймворка **BeeWare (Toga)**.

## ✨ Основные возможности

- **3 уровня сложности:** Новичок, Средний, Тяжелый.
- **База данных:** Более 250 уникальных вопросов с подробными пояснениями.
- **Раунды по 10 вопросов:** В рамках одного раунда вопросы не повторяются (выборка случайная).
- **Мгновенная обратная связь:** Подсветка правильных и неправильных ответов, а также пояснение к каждому вопросу.
- **Статистика:** Подсчет очков и итоговый экран после каждого раунда.
- **Нативный интерфейс:** Приложение собирается в `.apk` и отлично работает на Android.

## 🛠️ Стек технологий

- **Язык:** Python 3
- **UI Framework:** [Toga](https://toga.readthedocs.io/) (часть проекта BeeWare)
- **База данных:** SQLite3 (встроенная)
- **Упаковка:** Briefcase

## 🚀 Как запустить проект локально

Если вы хотите запустить проект на своем компьютере для разработки:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_НИК/PythonQuizApp.git
   cd PythonQuizApp
Создайте виртуальное окружение и установите зависимости:

bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Mac/Linux:
source .venv/bin/activate

pip install briefcase
Запустите приложение в режиме разработки:

bash
briefcase dev

📱 Как собрать APK для Android
Убедитесь, что у вас установлены Java 17 JDK и Android SDK (Briefcase скачает их автоматически при первом запуске).

bash
briefcase create android
briefcase build android
briefcase package android -p debug-apk
Готовый APK-файл появится в папке dist/.
